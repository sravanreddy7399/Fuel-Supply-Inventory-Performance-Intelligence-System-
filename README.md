# Fuel Supply & Inventory Performance Intelligence System (2025–2026)

An end-to-end analytics and BI project that monitors fuel inventory health, consumption trends, and stockout risk across multiple locations using Python and Power BI.

---

## Overview
This project builds a **risk-aware inventory monitoring system** that goes beyond historical reporting. It tracks inventory levels and consumption behavior to identify **early stockout risk**, support proactive replenishment decisions, and improve operational visibility.

Python is used for transparent KPI computation, while Power BI delivers interactive, decision-ready dashboards.

---

## Business Problem
Fuel inventory operations often suffer from:
- Sudden demand spikes
- Delayed replenishment cycles
- Hidden localized stockout risk

Averages alone can mask these issues. This system highlights **minimum coverage and trends** to surface risks early.

---

## Key Features
- KPIs: Average Days of Supply, Minimum Days of Supply, Average Inventory
- Time-series inventory and consumption trends
- Location-based slicers
- Visual risk indicators (healthy vs warning states)

---

## Architecture
- **Python (Jupyter / Colab):** Data cleaning, feature engineering, KPI logic  
- **Power BI:** Star-schema model, DAX measures, interactive dashboards
